# Potion Looker
Minecraft 26.2 Fabric client mod.

Features:
- Shows active effects of the player you are looking at
- HUD top-right
- Enable/disable
- Move HUD
- Cloth Config settings
- Press O for settings
- GitHub Actions builds the JAR automatically

After uploading this project to GitHub:
GitHub -> Actions -> Build Potion Looker -> latest run -> Artifacts -> PotionLooker
